# Tumbler

A quiet countryside in the browser: an alpine valley with a meandering river, a
village built into redwood trunks, meadows, and a ring of mountains. Walk it,
fly it (paraglider, parakite, paramotor), ski the cirque or ride the graded
trails.

**Live:** <https://tumbler.catronin.com>

## Run it locally

There is no build step and nothing to install. From the repository root:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Then open <http://127.0.0.1:8000/client/web/scene.html> for the 3D scene, or
<http://127.0.0.1:8000/client/web/> for the 2D map.

## What is here

- `client/web/`: the browser client. `scene.html` and `src3d/` are the 3D
  scene, `src/` the 2D map, and `vendor/` holds Three.js r180 (MIT, licence in
  `vendor/LICENSE.three`).
- `shared/activities/` and `shared/ecology/`: engine-neutral rules for flight,
  skiing and biking, collision, and water life, shared with other clients.
- `shared/world/` and `shared/geometry/`: the generated world data and the
  models the client reads.
- `client/web/data/viewer.json` lists every file the scene fetches with its
  sha256. The scene checks them all when it starts and stops on a mismatch.

## Tests

```sh
node --test client/web/tests/*.test.mjs
python3 -m unittest discover -s client/web/tests -t .
```

## How this repository is made

It is published from a private source repository each time that repository's
main branch changes: the world generator, the Unreal client and the model
sources live there. Files here are regenerated by that process, so edits made
here are overwritten. Two test files that check the full model library
(`glb.test.mjs`, `assets.test.mjs`) run there before every publish and are not
included here.

The site is static. `python3 client/web/tools/package_web.py` writes
`dist/web`, and Cloudflare Workers serves it (`wrangler.jsonc`). `npm ci`
installs the pinned Wrangler with install scripts disabled (`.npmrc`).
