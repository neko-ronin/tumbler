A map of committed core output, drawn in a browser. It is not a render, and the corner of the picture says so: no engine, no lighting, no aerial perspective. A browser cannot run Python, so this draws the files shared/ produced rather than running shared/ — see client/web/README.md. Every file it read is stamped with its digest, because a map drawn from stale data looks exactly like one drawn from current data.
